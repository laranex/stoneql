# Getting help

- **Using StoneQL:** the [user guide](https://stoneace.github.io/stoneql/guide/) covers downloading, installing, connecting to a database and everyday tasks.
- **Something isn't working:** check [Troubleshooting](https://stoneace.github.io/stoneql/guide/troubleshooting) for first-launch approval, Keychain prompts and connection errors.
- **Found a bug or want a feature:** [open an issue](https://github.com/stoneAce/stoneql/issues/new/choose) with the matching template.
- **Security problem:** follow [SECURITY.md](SECURITY.md); do not open a public issue.
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md) and the [Developer Docs](https://stoneace.github.io/stoneql/development/).
